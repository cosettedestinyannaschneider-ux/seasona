# 拾季前端

这里是拾季项目的 Vue 3 + Vite 前端。当前前端已经覆盖买家端、卖家端、管理员端和小拾 AI 导购界面。

## 技术栈

- Vue 3
- Vite
- Vue Router
- Pinia
- Axios
- Lucide Vue Next

## 本地开发

```bash
npm install
npm run dev
```

默认开发端口为 `5173`。`vite.config.js` 会把 `/api` 和 `/media` 代理到 `http://127.0.0.1:8000`。

如需指定后端地址，可创建 `frontend/vite/.env`：

```env
VITE_API_BASE_URL=http://127.0.0.1:8000
```

留空时使用同源路径，适合 Docker + Nginx 部署。

## 构建

```bash
npm run build
```

构建结果输出到 `../dist`，也就是 `frontend/dist`。

## 页面模块

- 买家端：首页、商城、商品详情、店铺页、购物车、下单、订单、订单详情、钱包、评价、地址簿、资料编辑、忘记密码、小拾。
- 卖家端：控制台、资质审核、店铺资料、商品管理、订单履约、评价回复、收益钱包。
- 管理员端：控制台、用户管理、商家审核、商品审核/下架、分类管理、争议处理、搜索索引。

## 接口原则

- 前端只调用后端实际存在的 API。
- 所有角色权限以后端校验为准，前端跳转和隐藏按钮只做体验辅助。
- 商品下单、付款、退款等资金相关操作不会信任前端缓存数据。
